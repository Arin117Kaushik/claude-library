# Obsidian plugins and look

Every Obsidian plugin, theme and snippet behind my vault's look.

Generated from the [Claude Library](https://github.com/Arin117Kaushik/claude-library). Updated 25 Nov 2026.

## Plugins

- **Notebook Navigator** by Johan Sanneblad: Replaces the file explorer with a two-pane view: folder tree on one side, note previews on the other. The biggest single change to how the vault feels. [Open in Obsidian](obsidian://show-plugin?id=notebook-navigator) · [Plugin page](https://obsidian.md/plugins?id=notebook-navigator)
- **Iconize** by Florian Woelki: Adds icons to files, folders and text. Each numbered folder gets its own icon. [Open in Obsidian](obsidian://show-plugin?id=obsidian-icon-folder) · [Plugin page](https://obsidian.md/plugins?id=obsidian-icon-folder)
- **Style Settings** by mgmeyers: Controls for theme, plugin and snippet CSS variables. Tunes the theme without editing CSS. [Open in Obsidian](obsidian://show-plugin?id=obsidian-style-settings) · [Plugin page](https://obsidian.md/plugins?id=obsidian-style-settings)
- **Custom Font Loader** by Amir Pourmand: Load any font into Obsidian, on desktop and mobile. Sets the reading and interface fonts. [Open in Obsidian](obsidian://show-plugin?id=custom-font-loader) · [Plugin page](https://obsidian.md/plugins?id=custom-font-loader)
- **Beautitab** by Andrew McGivery: A new tab page with backgrounds, quotes and search. Empty tabs look intentional instead of blank. [Open in Obsidian](obsidian://show-plugin?id=beautitab) · [Plugin page](https://obsidian.md/plugins?id=beautitab)
- **Homepage** by novov: Opens a chosen note, canvas or workspace on startup. Obsidian always opens on HOME.md. [Open in Obsidian](obsidian://show-plugin?id=homepage) · [Plugin page](https://obsidian.md/plugins?id=homepage)
- **Mononote** by Carlo Zottmann: Each note gets only one tab. Opening it again focuses the existing tab. No more five copies of the same note. [Open in Obsidian](obsidian://show-plugin?id=mononote) · [Plugin page](https://obsidian.md/plugins?id=mononote)
- **Doubleshift** by Qwyntex: Press Shift twice to open the command palette. Fast commands without a hand stretch. [Open in Obsidian](obsidian://show-plugin?id=obsidian-doubleshift) · [Plugin page](https://obsidian.md/plugins?id=obsidian-doubleshift)
- **Various Complements** by tadashi-aikawa: IDE-style autocomplete for words, links and tags. Fewer typos in note names and tags. [Open in Obsidian](obsidian://show-plugin?id=various-complements) · [Plugin page](https://obsidian.md/plugins?id=various-complements)
- **Easy Typing** by yaozhuwa: Auto formatting while typing: spacing, capitals, symbol pairs. Cleaner notes with no effort. [Open in Obsidian](obsidian://show-plugin?id=easy-typing-obsidian) · [Plugin page](https://obsidian.md/plugins?id=easy-typing-obsidian)
- **Smart Typography** by mgmeyers: Curly quotes and ellipses as you type. Turn its dash conversion off if you, like me, ban em dashes. [Open in Obsidian](obsidian://show-plugin?id=obsidian-smart-typography) · [Plugin page](https://obsidian.md/plugins?id=obsidian-smart-typography)
- **Paste URL into selection** by Denis Olehov: Select text, paste a URL, get a markdown link. Inline links in one keystroke. [Open in Obsidian](obsidian://show-plugin?id=url-into-selection) · [Plugin page](https://obsidian.md/plugins?id=url-into-selection)
- **Local REST API** by Adam Coddington: A secure local API and MCP server for the vault. How Claude reads and edits the open vault. [Open in Obsidian](obsidian://show-plugin?id=obsidian-local-rest-api) · [Plugin page](https://obsidian.md/plugins?id=obsidian-local-rest-api)

## Themes

- **Vanilla AMOLED**: The active theme. True black background, built for OLED screens. My accent color is #9630c5. [Open in Obsidian](obsidian://show-theme?name=Vanilla%20AMOLED)
- **Minimal**: A clean, very configurable theme. A good base with Style Settings. [Open in Obsidian](obsidian://show-theme?name=Minimal)
- **Things**: Inspired by the Things to-do app. Soft and readable. [Open in Obsidian](obsidian://show-theme?name=Things)
- **Tokyo Night**: A dark blue theme from the editor color scheme of the same name. [Open in Obsidian](obsidian://show-theme?name=Tokyo%20Night)
- **Border**: Rounded cards and soft borders around every pane. [Open in Obsidian](obsidian://show-theme?name=Border)

## Snippets

- **Colored Sidebar Items** by CyanVoxel: Colors every folder that starts with a number prefix, so 01 to 06 each get their own color in the sidebar. Drop it in .obsidian/snippets and turn it on under Appearance. [Download CSS](kit/obsidian/colored-sidebar-items.css)

## Core plugins

- **Bases**: Database views over notes and their properties.
- **Canvas**: Infinite boards for mapping ideas.
- **Daily notes**: One note per day, opened with a click.
- **Templates**: Inserts the three-line note template.
- **Graph view**: The map of every link in the vault.
- **Backlinks and outline**: What links here, and the heading tree of the open note.
- **Bookmarks**: Pinned notes and searches.
- **Slides**: Turns a note into a quick presentation.
- **File recovery**: Snapshots that rescue overwritten notes.

## The look

- **Theme**: Vanilla AMOLED, true black.
- **Accent**: Purple, #9630c5.
- **Base font size**: 14 px, set in Appearance.
- **Sidebar**: Notebook Navigator with Iconize icons and the colored sidebar snippet.
- **Startup**: Homepage plugin opens HOME.md every time.
